# mangekyou

Aplicação Web construída com **Django** e **Bootstrap 5** para criação de um site dinâmico e responsivo.

---

## 📌 Sobre

O **Mangekyou** é um projeto web que combina a robustez do framework Django (Python) com a interface moderna e responsiva do Bootstrap 5. O objetivo é servir como base para aplicações web, portfólios, blogs ou painéis administrativos.

---

## 🧠 Tecnologias

- Python  
- Django  
- Bootstrap 5  
- HTML / CSS  
- SQLite (banco de dados padrão para desenvolvimento)

---

## 🚀 Funcionalidades

- Estrutura básica de aplicação Django  
- Layout responsivo com Bootstrap 5  
- Páginas base (`home`, etc.) já configuradas  
- Possibilidade de expandir para CRUDs e dashboards

---

## 🛠️ Pré-requisitos

Este projeto usa Python e Django. Antes de rodar garanta que você tem:

- Python 3.8+ instalado  
- `pip` para instalar dependências  
- (opcional) um ambiente virtual (`venv`)
